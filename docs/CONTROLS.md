# FACET FIGHTER — controls

Use a PlayStation digital controller, or a DualShock with its D-pad.

| Button | Action |
|---|---|
| Left / Right | Move along the camera's fighting axis |
| Down / Up | Crouch / Jump |
| Square | High punch |
| Triangle | Mid kick |
| Cross | Guard |
| Circle or Square + Cross | Throw |
| Down + Triangle | Low kick |
| Square + Triangle | Heavy kick |
| R2 | Shoulder ram: advancing mid attack, knockdown, strong pushback |
| L1 / R1 | Circle the opponent |
| Start | Confirm / Pause or resume |
| Select while paused | Return to title |

Standing guard blocks high and mid strikes. Crouching guard blocks low strikes.
Crouching evades high punches and standing throws. Jumping avoids low kicks.

A round ends on KO, ring-out, or the 30-second time limit. More remaining health
wins a time-out. Equal health or simultaneous defeats are draws and award no
round win. First to two round wins wins the match.

ARCADE: three CPU matches. 2P VERSUS: two controllers, character selection and
rematches. On a result screen, Start restarts and Select returns to the title.
